Integritetspolicy – Lilla Företagshjälpen

Lilla Företagshjälpen är en lokal applikation för fakturering och enkel administration avsedd för småföretagare.

Applikationen samlar inte in, lagrar eller överför några personuppgifter till utvecklaren eller till tredje part.

All information som användaren själv matar in i applikationen (såsom fakturauppgifter, belopp och kundinformation) lagras lokalt på användarens egen enhet.

Om användaren väljer att exportera filer eller ladda upp data till en extern molntjänst eller lagringslösning sker detta helt på användarens eget initiativ och ansvar. Utvecklaren har ingen åtkomst till dessa data och ansvarar inte för hur externa tjänster hanterar informationen.

Applikationen använder inga spårningstekniker, inga annonser och ingen användarprofilering.

Vid frågor om integritet eller applikationen, kontakta utvecklaren via den plattform där applikationen tillhandahålls.

Privacy Policy – Lilla Företagshjälpen

Lilla Företagshjälpen is a local desktop application for invoicing and basic administration for small businesses.

The application does not collect, store, or transmit any personal data to the developer or to third parties.

All data entered by the user (such as invoice details, amounts, and customer information) is stored locally on the user’s own device.

If the user chooses to export files or upload data to an external cloud service or storage provider, this is done entirely at the user’s own initiative and responsibility. The developer has no access to such data and is not responsible for how external services handle it.

The application does not use tracking technologies, advertisements, or user profiling.

For privacy-related questions, please contact the developer via the platform where the application is distributed.
